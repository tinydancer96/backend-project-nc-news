POST /api/articles/:article_id/comment

Makes a new comment for an article

Example code

        
            { "username": "tinydancer96", "body": "Hi there, new comment for article 2" }

PATCH /api/articles/:article_id

Increments or decrements votes for an article

Example code

        
            { "inc_votes": 1 }

GET api/comments/:comment_id

                                }
                            ]
            }

DELETE /api/comments/:comment_id

Deletes a comment. Send a delete request via the url and the comment will be deleted
